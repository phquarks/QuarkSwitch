## Scope and mode

Native macOS menu-bar application onboarding and Settings. Operate mode.

## Audience and job

Russian/English Mac users need quiet correction of accidental keyboard-layout mistakes without surrendering typing privacy or control.

## Task and content

The first-run path explains local-only behavior, requests Accessibility and Input Monitoring separately, and ends in an explicit full-access or limited-access state. Settings expose enablement, confidence, shortcuts, languages, exceptions, application exclusions, privacy, and aggregate statistics.

## Chosen direction

Restrained native redline editor, grounded direction 3, seed `4febd1bf`. Graphite system surfaces, system accent, hairline divisions, compact controls, and a before/after correction mark make the product mechanism visible without turning the utility into a dashboard.

## Memorable moment

The input cursor and `ghbdtn → привет` redline establish the mechanism before the permission request. The interface then recedes into the menu bar.

## Constraints

Follow public macOS APIs, VoiceOver and keyboard conventions; preserve one clear action per onboarding step; never display or persist typed content as history.
